# Database Setup

1. Create PostgreSQL database.

2. Run application once using:

spring.jpa.hibernate.ddl-auto=update

3. Execute:

sample-data.sql

4. Start backend application.

The script inserts sample categories and products for testing:
- Pagination
- Sorting
- Search
- Cart
- Wishlist
- Orders


## Sample Data

The repository contains:

database/sample-data.sql

Run this script to populate sample categories and products.
